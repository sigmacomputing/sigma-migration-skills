# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities through Sigma's Vulnerability Disclosure
Program: **https://www.sigmacomputing.com/product/vdp**

Do **not** open public GitHub issues or pull requests for security reports.

## Scope

These skills run locally in your coding agent and act against **your own** Sigma
org and source-BI-tool credentials, which you supply through environment
variables (`~/.sigma-migration/env` or your agent's settings). This repository
contains no secrets. When reporting an issue, never include real credentials,
tokens, customer data, or connection identifiers.
